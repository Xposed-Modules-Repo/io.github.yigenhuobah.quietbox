# 静盒 (QuietBox)

一个面向小红书的 LSPosed 模块：去掉广告、收敛弹窗、收紧隐私，让 App 安静下来。

- 基于 libxposed Modern API 102，纯 Java Hook
- 不修改目标应用安装包，不拦截网络请求，无后台服务、无 native 库
- 不申请网络权限，无统计与遥测

> ⚠️ 本项目与小红书官方无任何关联，仅供学习、研究和个人设备使用。

## 功能

共 24 项，**21 项可用**，每项独立开关、默认关闭。改动立即生效（AB 测试面板首次启用需重启一次小红书）。

**广告**

- 开屏广告跳过（内嵌 Fragment / 全屏 Activity / 冷启动占位三条路径）
- 信息流广告过滤
- 评论广告过滤
- 广告外跳拦截
- 搜索广告过滤
- 详情页广告条屏蔽
- 评论区带货插入屏蔽
- 直播卡过滤 / 带货卡过滤 / 投票卡过滤（信息流里不显示这三类卡片）

**打扰与引导**

- 评分引导弹窗屏蔽（应用内评分 + 系统评分）
- 通知引导弹窗屏蔽（手动开通知不受影响）
- 满意度调研条屏蔽

**内容与浏览**

- 已删除笔记查看（实验性：用本地已缓存的内容继续展示，无缓存时不伪造内容；该恢复路径未在真实被删笔记场景实测）

**界面与隐私**

- 更新弹窗屏蔽
- 截图检测关闭
- 通讯录同步关闭（不上传通讯录，也不再有通讯录推荐好友）

**分享与播放**

- 复制链接净化（可选删除 xsec_token）
- 保存图片去水印
- 自动播放与画质偏好

**测试（实验开关）**

- AB 测试面板：内置 21 个高价值、纯客户端的实验开关（详情页渲染、播放体验、评论键盘、首页预加载等），每项独立开关；最底部展示模块探测到的其他实验 key（只读，不建议修改）；支持把全量 key + 当前探测值导出为 CSV

> 强开的是灰度实验组，不是隐藏福利。部分实验依赖服务端配套数据，可能出现页面空白或崩溃，请逐项验证。

**本版本不提供**：默认静音（应用自带）、摇一摇拦截（检测在原生层）、埋点抑制（无安全挂载点）。

**版本不兼容提示**：小红书升级后挂载点可能大面积失效，此时静盒顶部会出现红色提示。这是预期行为，先确认小红书版本是 9.50.0。

## 环境要求

- Android 10 及以上
- 已安装 LSPosed（Zygisk 版）
- 小红书 **9.50.0（9500803）**

其他版本可能只有部分功能生效。

## 安装

1. 从 Releases 下载 APK 并安装
2. 在 LSPosed 管理器中启用「静盒」
3. 作用域勾选 **小红书**（`com.xingin.xhs`）
4. 打开静盒，确认顶部显示「已激活 · 已注入小红书」
5. 按需打开开关

**更新模块后需要重启小红书**（本模块未启用热重载）。

## 常见问题

**开关是灰色的？** 模块 App 还没绑定到 LSPosed 服务，等一两秒会自动刷新；一直灰着请检查模块是否启用、作用域是否勾选。

**某项没效果？** 看 logcat（tag `QuietBox`）。注册成功会打印 `P1-13 registered ...`，命中会打印 `P1-13 hit ...`。没有注册日志说明该版本的挂载点没找到。

**AB 测试面板怎么用？** 打开面板总开关 → 重启小红书 → 回到面板逐项强开。改单个开关后回到小红书约 3 秒生效。面板最底部的「其他」是探测到的未收录实验，只读；点「导出全量实验」可以把全量 key + 当前值存成 CSV。

**升级小红书后失效？** 正常现象，模块依赖具体版本的内部结构。若顶部出现红色不兼容提示，可先回退到 9.50.0。

**会不会封号？** 模块不修改账号数据、不拦截网络请求、不上传任何信息，但确实会 Hook 目标应用进程，理论上存在被检测的可能。是否用于主账号请自行评估。
